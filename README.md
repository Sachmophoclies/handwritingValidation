# handwritingValidation

A small phone-friendly site for validating transcriptions of handwritten recipe cards: one zoomable card image and its question per page, then a downloadable results file.

- Answers are saved in the browser (localStorage) and exported as `Followups_answered.txt`.
- Content comes from `public/data/items.json` and `public/images/`, which are generated by the export script in the private recipe project (`Data/tools/export_validation_site.py`). Do not edit them by hand.
- Develop: `npm install`, `npm run dev`. Build: `npm run build`. Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
- The page is `noindex`; this site is short-lived and public by design.
